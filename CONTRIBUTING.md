# Contributing

Thanks for your interest in contributing to this portfolio. This repository is primarily a personal website, but contributions that improve documentation, accessibility, or portability are welcome.

How to contribute
- Fork the repository and create a branch for your change.
- Open a pull request with a clear description of the change and why it's needed.
- Keep changes small and focused. Add tests or screenshots where relevant.

Code style
- The project uses Tailwind CSS and TypeScript. Keep formatting consistent and run the formatter if one is configured.

Reporting issues
- Open an issue with steps to reproduce, expected behavior, and any relevant environment details.

By contributing, you agree that your contributions will be licensed under the project's license.
