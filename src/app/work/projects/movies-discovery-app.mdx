## Overview

Movies discovery isn’t just “search results” — the real UX is **discover → evaluate → save**. This app supports that flow with fast search, rich details (including trailers), and account-based persistence for favorites and recent searches.

### What it does

- **Discovery**: search across movies/TV, browse trending weekly titles
- **Decision support**: detail view with genres, ratings, runtime, and an embedded YouTube trailer
- **Exploration**: related/similar titles to keep users in the funnel
- **Personalization**: favorites saved per user + recent search history (capped)
- **Instrumentation (optional)**: record popular searches in Appwrite as a lightweight analytics layer

## Architecture

- **React client (Vite)** calls **TMDB directly** for search/trending/details/trailers.
- **Node/Express API** handles **auth and user-owned data**: favorites + search history.
- **MongoDB** persists user profiles, favorites, and history.
- **Appwrite (optional)** stores search-term counts for basic product analytics.

## Engineering Highlights

- **Clear boundary between public vs user-owned data**: TMDB for catalog; backend only for data that must be tied to a user.
- **Predictable persistence**: bounded search-history size to avoid unbounded document growth.
- **Production-minded auth**: JWT + bcrypt password hashing; protected routes for authenticated areas.
- **UX polish**: loading/error states, responsive layout, and interaction patterns that keep the user moving (search → click → trailer → save).
